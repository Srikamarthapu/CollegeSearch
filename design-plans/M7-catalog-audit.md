# M7 Catalog UI Audit

Audit scope: current 3,912-institution release; directory cards, institution profiles, compare, broad-field pages, methodology, and match location controls. The source review below is followed by completed local rendered verification; hosted verification is recorded at release handoff.

The in-app methodology page is the current semantic reference for federal measure definitions. `design-qa.md` is a historical visual capture, not a content specification. Governing code includes `app/lib/college-data.ts`, `app/majors/major-data.ts`, `app/compare/page.tsx`, `app/CollegeCompassApp.tsx`, `app/majors/[slug]/page.tsx`, and `app/colleges/[slug]/page.tsx`. No explicit exceptions were found.

Validated in source: cards and profiles identify ownership; major cards and comparison headers display ownership; tuition labels distinguish public, private, and mixed comparisons; null observations render as “Not reported” rather than zero; negative average net prices carry an explanation; directory and lookup responses are bounded (24 by default, maximum 48), and comparison selection is capped at four institutions. The directory and broad-field pages use location-neutral “All locations” copy.

No product source was edited during this audit. All source-level findings are resolved in the working tree. Root owns the final rendered rebuild and browser QA.

## Rendered verification — October 4, 2026

Root verified the native production build at desktop, 390 px, and 320 px widths. Search returned Appalachian State and Baylor with loaded official local icons; both saved into My colleges and opened together in Compare. Two-year filtering returned 1,426 colleges; “Show 24 more” displayed 48 records with no horizontal overflow at 320 px. The associate-only comparison shows all 38 field choices, correct ownership/level headers, and the exact completion definition. Browser console review showed no errors/warnings during these flows.

The mobile sort label was hidden visually and consequently unnamed to assistive technology. SelectField now carries its explicit accessible label at every breakpoint; hosted rendered verification is recorded with the deployment handoff. Search suggestions disable pointer interception as they close, avoiding a quick subsequent click hitting a fading suggestion. All original source findings have passed rendered route tests.

Moorpark's source-reported negative average net price exposed a crowded metric grid at 320 px. The explanatory note now spans the card beneath all metrics; at 380 px and below, price occupies a full row with admission and completion beneath it. Rendered mobile and desktop checks confirmed readable values, missing-data labels, and the complete explanation without horizontal overflow.
